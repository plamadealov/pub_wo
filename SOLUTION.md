# Описание решения (CAPM + VaR + ES, новости)

Учебный проект. Код и документация живут **только** в этой папке. Секреты — **только** в локальных файлах, которые не коммитятся (например `.env`); приложение читает их через переменные окружения, **содержимое этих файлов в репозиторий не попадает**.

## Ограничения по данным и брокеру

- **Без авторизации реального счёта Т‑Инвестиций** и без OAuth пользователя.
- Источники данных:
  1. **Публичные рыночные данные** (приоритет для воспроизводимости): например **MOEX ISS** (исторические котировки, индекс для «рынка») — без персонального доступа к брокеру.
  2. **Опционально**: **sandbox / read-only токен T‑Invest API** (если выдан в кабинете разработчика), только для котировок и справочника инструментов — токен хранится в `.env`, код лишь подставляет `os.environ[...]`.

Тикеры в UI вводятся в **привычной форме** (тикер на MOEX или идентификатор, согласованный в коде); внутренне бэкенд маппит их на **FIGI / SECID / режим рынка** в зависимости от выбранного провайдера.

## Роли компонентов (бэкенд — ок)

- **Market data service**: загрузка и кэш истории цен (дневные доходности), выравнивание календаря, валюта (по умолчанию приведение к одной валюте или явное «только RUB»).
- **Analytics core** (чистая логика):
  - **CAPM**: оценка **β** по относительно выбранного рыночного индекса; портфельная **β** по весам; при заданных **Rf** и **E(Rm)** — ожидаемая доходность по CAPM (входы фиксируются в конфиге/константах или задаются в UI как «сценарий»).
  - **VaR**: исторический **1‑дневный** VaR на окне **1–2 года** (настраиваемый горизонн в торговых днях), уровни **95% / 99%**.
  - **ES (Expected Shortfall)** — в проекте термин **«пробой»** = **ES**: средний убыток в α‑хвосте распределения портфельной доходности (согласованно с выбранным VaR‑уровнем).
- **News service**: сбор заголовков/ссылок **за последние 24 часа** по каждому тикеру; агрегация **по портфелю** (объединённая лента с тегом тикера). Провайдер новостей — внешний публичный API или RSS; ключи (если есть) — только в `.env`.

## Хранилище

- Кэш OHLCV (SQLite или файлы в подкаталоге внутри проекта) — чтобы не дергать API на каждый пересчёт.
- Сессия пользователя для учебного режима: **без полноценной multi-user auth** — достаточно состояния на клиенте + опциональный `session_id` в cookie, либо один пользователь локально.

## Фронтенд (требования к виду)

1. **Ввод и добавление тикеров**: поле тикера, сумма или доля (или только доли, нормализуемые к 100%); список позиций с удалением/редактированием; кнопка «пересчитать».
2. **Вывод метрик**:
   - **Портфель**: веса, портфельная β, VaR, **ES**, краткие пояснения к окну данных и уровню доверия.
   - **По тикеру** (при выборе строки или раскрытии карточки): β, вклад в портфельную β, маржинальные VaR/ES при необходимости (опционально во 2-й итерации).
3. **Новости**: блок «по портфелю» (все тикеры) и «по выбранному тикеру»; время публикации в пределах 24 ч.

## Поток пользователя

1. Задаёт портфель (тикер + сумма/доля) или стартовый набор из пресета.
2. Выбирает **профиль** «консервативность ↔ доходность» → перевод в ограничения (макс. вес в одном тикере, мин. доля «защитных» классов и т.д.) — **политика**, не замена CAPM.
3. Бэкенд тянет историю, считает **CAPM‑метрики**, **VaR**, **ES**, отдаёт JSON.
4. Пользователь добавляет тикер → пересчёт той же цепочки.
5. Открывает карточку тикера → график цены (из кэша котировок) + новости за сутки.

## Дисклеймер

Инструмент **учебный**; расчёты и новости не являются персональной инвестиционной рекомендацией.

## Переменные окружения (без значений)

Пример имён (реальные значения только у вас локально):

- `MOEX_ISS_USER_AGENT` — при необходимости для MOEX.
- `TINVEST_TOKEN` — **только** если используете sandbox/read-only T‑Invest API; иначе опустить.
- `NEWS_API_KEY` или аналог — если выбранный провайдер новостей требует ключ.

Код читает переменные; файлы `.env` не коммитятся (см. `.gitignore`).

## Локальный запуск (стек)

- **Бэкенд:** FastAPI на `127.0.0.1:8000`, префикс маршрутов **`/api/...`**.
- **Фронтенд:** Vite dev server на `http://localhost:5173`, **proxy** `/api` → бэкенд (см. `frontend/vite.config.ts`). Дополнительно включён CORS в FastAPI для тех же origin.
- Пошаговые команды: [README.md](./README.md).
